# 계획 파일 최소 형식

설정 `planSkill`이 비어 있는 저장소에서 쓰는 형식이다. 이미 계획 스킬이 있으면 그 형식을 쓰되, 아래 **테스트 줄** 조건만 맞추면 된다. 파일 위치는 설정 `planGlob`(기본 `plans/issue-{issue}*.md`).

```markdown
# 이슈 <N> — <제목>

## 범위
- 한다: …
- 하지 않는다: …          ← pr-reviewer가 이 목록을 요구하지 않는다

## 수용 기준
- AC-1: …
- AC-2: …

## 절차
1. [ ] <절차 1 — 무엇을 어디에>
   - [ ] T01: <한 문장으로 된 테스트 — 입력·조건 → 기대 결과> (AC-1)
   - [ ] T02: … (AC-1)
2. [ ] <절차 2>
   - [ ] T03: … (AC-2)

## 가정
- [가정 1] …
```

- **테스트 줄**: `- [ ] T<NN>: <문장>` 한 줄이 테스트 하나다. test-writer는 이 줄마다 테스트를 하나 만들고 이름을 `T<NN>:`으로 시작한다. GATE-1 검토는 줄 수와 테스트 수가 같은지로 1:1을 본다.
- **체크박스**: 마스터가 절차를 끝낼 때마다 `[x]`로 바꾼다. GATE-3에서 전부 `[x]`여야 한다.
- 계획은 마스터를 부르기 전에 검토 세션의 계획 검토를 받는다.
