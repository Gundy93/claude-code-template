# PR 본문 기본 템플릿

설정 `prSkill`이 비어 있을 때 쓴다. 저장소에 PR 템플릿(`.github/pull_request_template.md`)이나 CLAUDE.md의 PR 규약이 있으면 그것이 이긴다.

```markdown
<스택 PR이면 첫 줄: base: #<선행 PR> (<base 브랜치명>) — 선행 머지 뒤 base가 바뀐다>

## 개요
<무엇을 왜 — 두세 문장>

Closes #<이슈>

## 변경 사항
- <파일·모듈 단위 요약>

## 확인할 것
- [ ] <리뷰어가 직접 확인할 동작>

## 검증
- 계획: <경로>
- 테스트: <명령> → 통과 N (이 PR이 더한 테스트 M개 — 계획 T01~T<NN>)
- 테스트 동결: RED <sha> 이후 테스트 경로 무변경(testdiff)
- 크기: 파일 N개 · 최대 파일 M줄 (<base>...HEAD)
```

- 머지로 이슈를 닫으려면 `Closes #<이슈>` 같은 닫기 키워드가 있어야 한다(제목의 번호나 "#이슈 참조"로는 닫히지 않는다). 키워드는 PR이 기본 브랜치를 대상으로 할 때만 동작한다 — 스택 PR은 base가 기본 브랜치로 바뀐 뒤 머지돼야 닫힌다.
- 실행하지 않은 검증은 쓰지 않는다. 못 돌렸으면 「미실행 — 사유」로 적는다.
